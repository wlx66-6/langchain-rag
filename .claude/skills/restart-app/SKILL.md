# 重启前后端服务

改了后端或前端代码后，需要**停掉旧进程、再重新启动**，才能看到新效果。本技能就是干这个的。

## 为什么改完代码要重启

- **后端**：FastAPI 跑起来后，代码是「启动时读进内存」的，改了 `.py` 文件不会自动生效，必须重启。
- **前端**：Vite 开发服务一般有「热更新」（改代码自动刷新），但改了配置文件（如 `vite.config.ts`）或端口被占时，也要手动重启。

## 重启步骤

### 1. 停掉旧服务

- 如果是由 `start.bat` 弹出的两个黑色窗口启动的，直接**关掉那两个窗口**（标题分别是 `RAG-Backend` 和 `RAG-Frontend`）。
- 如果找不到窗口了（窗口关了但进程还残留），按端口干掉残留进程（Windows）：

```bash
# 查出占用 8000（后端）、5173（前端）端口的进程
netstat -ano | findstr :8000
netstat -ano | findstr :5173
# 看每行最后一列的 PID，再：
taskkill /F /PID <那个PID>
```

### 2. 重新启动

双击 `start.bat`；或交给 `run-app` 技能代为后台启动。

## 注意事项

- 重启**不会丢数据**：会话记录、知识库文件都在 `backend/data/` 里持久化，放心重来。
- **先停干净再启动**，否则端口占用会导致启动失败。
